How to review AI edits in Rendprop and compare with the original

Every AI edit in Rendprop is a separate version beside the untouched original. Compare each for invented or missing details, then pick the versions to use.

Rendprop saves every AI edit as a separate version with a disclosure and keeps the untouched original in photo history, so the comparison is always available; the job is to actually do it, for every photo, before anything is published.

Why the comparison is the step, not a formality

AI edits can change or invent details. A blue sky edit can also lighten a roof. A tidy-the-room edit can remove a cord and, while it is at it, remove an outlet. An add-furniture edit can put a sofa where the fireplace hearth is. None of this is visible if you only look at the edited photo, because the edited photo looks plausible. It is only visible side by side with the original. That is why Rendprop keeps both and why the version you did not choose is still there afterwards.

The review, one photo at a time

  1. Open the listing and go to the photo studio.
  2. Pick a photo that has one or more edited versions.
  3. Compare the edit with the original. Look at the whole frame, then the edges, then the details that identify the room.
  4. Decide: keep the edit, keep the original, or try a different edit. Each attempt is its own version; nothing overwrites the original.
  5. Choose which saved versions to use in the video and the gallery.
  6. Move to the next photo. Do not skip the ones that "look fine"; those are the ones that catch you.

What to look at in the comparison

  • Count things. Windows, doors, outlets, light switches, cabinet handles, ceiling fixtures. The numbers must match.
  • Check fixed features. Fireplace, built-ins, radiator, stair rail, the kitchen island. Same place, same size, same shape.
  • Check the view. Through every window, is it the same street, fence, tree, neighbour's wall?
  • Check surfaces. Floor material, counter material, wall colour. A twilight edit that warms the floor from oak to walnut has changed the house.
  • Check what was removed. With tidy the room, confirm only loose clutter went, not a cabinet, a vent or a crack that a buyer has a right to see.
  • Check what was added. With add furniture, confirm nothing new is structural: no new window, no second door, no wall where there was none.

A worked example: the kitchen on a Tuesday evening

You have a 3-bed in a cul-de-sac, listed Tuesday, open house Saturday. The kitchen was shot with a toaster, a paper towel roll and a drying rack on the counter, so you run tidy the room. The edit looks clean. Side by side with the original, the toaster, the roll and the rack are gone, which is what you wanted. But the outlet behind the toaster is also gone, and the backsplash grout line runs straight through where it was.

That is a changed room. You try a custom prompt instead, asking to remove only the loose items on the counter and keep the outlet. The new version is a second edit, separate from the first. This time the outlet is where it was. You choose that version for the gallery and the video. The first edit stays in history, unused, and the original is still there untouched. Total time for one photo: about ninety seconds. Across a set of 20, the ten-minute batch review is a realistic target once you have the rhythm.

Which edits deserve the hardest look

Add furniture, because it changes a room's apparent size and layout and is labelled "Virtually staged" for that reason. Tidy the room, because removal is quiet and easy to miss. Custom prompts, because a loose instruction gets a loose result. Blue sky and green lawn are usually safer but still worth the count, since a sky edit can change the brightness of a whole exterior and a lawn edit can creep onto a driveway.

Mistakes that get through when the review is rushed

  • Glancing instead of looking. Look long enough, and close enough, to count the outlets.
  • Comparing edit to edit. Compare each edit to the original, not to the previous edit; drift accumulates.
  • Keeping the prettiest version by default. Prettier and true are different tests. Keep the true one.
  • Assuming the disclosure covers the problem. The label tells a buyer the photo was altered; it does not make a removed outlet acceptable.
  • Forgetting the MLS. Check your own MLS rules before posting altered images, label or not.

What the app keeps for you

Every edit is a separate version with a disclosure. Staging is labelled "Virtually staged"; other edits carry an AI-alteration disclosure. The original stays in photo history. You decide which versions are used; the rest remain. The photo studio section describes the edit types, and the labelling post explains what each disclosure says.

Next step: open your most recent listing, pick the one photo you edited the most, and put it next to its original. Count the outlets. Then do the rest.

FAQ

Questions on this topic

Does an AI edit replace my original photo?

No. Each edit is saved as a separate version with a disclosure, and the untouched original stays in photo history. You choose which saved versions to use.

What should I compare first?

Counts and fixed features: windows, doors, outlets, the fireplace, the island, the view through each window. If any of those changed, use the original or try a narrower edit.

Can I try more than one edit on the same photo?

Yes. Each attempt becomes its own version. Compare each one against the original rather than against the previous attempt.

If I keep an edit, do I still need to tell anyone?

The version carries its disclosure, and staging is labelled Virtually staged. You should still check your own MLS rules before posting altered images, and compare against your originals before publishing.
