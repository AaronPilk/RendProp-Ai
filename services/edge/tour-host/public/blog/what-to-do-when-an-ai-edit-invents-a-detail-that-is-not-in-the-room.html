When an AI edit invents a detail that is not in the room

Do not publish it. Go back to the original, re-run with a prompt that names the invented detail, and if it happens again use the original.

The invented detail is the problem. The fix is the original.

What counts as an invented detail

Anything in the edited photo that is not in the room and was not asked for. A second window on a wall that has one. A ceiling fan where there was a flush light. A patch of hardwood where the carpet meets the hall. A door that leads nowhere. A path light on a lawn with no wiring. Text on an appliance that is not a word. A reflection in a mirror that shows a different room.

Some are obvious. Most are not, which is why you compare every edit against its original and count openings, fixtures and surfaces before choosing it. The post on how to compare an AI-edited listing photo against the original has the count.

The decision, in order

  1. Reject the version. It does not go in the gallery, the video or the social cut. The original is the fallback and it is already there.
  2. Ask whether the edit matters. A sky swap on the fourth exterior frame is not worth a second run. A staged living room on a vacant listing probably is.
  3. Name the invention in the new prompt. Keep the wall to the right of the fireplace blank with no window. Keep the ceiling fan. Keep the carpet in the doorway. The model invented it because the prompt left room; close the room.
  4. Compare again. Same count. A second version can fix the first invention and add a new one.
  5. Two strikes, use the original. If the second run also invents, the frame is not a good candidate for that edit. Publish the original and move on.

A worked example: the dining room with the extra door

An agent runs a tidy-the-room edit on a dining room to remove a high chair and a stack of boxes. The edit comes back clean, and in the corner where the boxes were there is now a door. The original has a blank wall.

Rejected. The edit matters, because the boxes make the room look like storage. Second run: Remove the high chair and the boxes. Keep the wall behind the boxes blank with no door, window or fixture. Keep the floor, the window and the light exactly as they are. The second version comes back with the boxes gone and a blank wall. Count passes. Published with an AI-alteration disclosure, original kept.

If it is already live

Swap the photo for the original or the corrected version the same day, everywhere it appears: the MLS, the property page, the social post. Then add a line to the remarks saying one photo was replaced. If a buyer has already asked about the detail, tell them plainly that the edit added something that is not there and show them the original. That conversation is short when you have the original and the version history, and long when you do not. Keeping original photos is the reason this is a short conversation.

Why it happens, so you can reduce it

An image model fills the space you ask it to change with the most likely content. A blank wall where boxes were is less likely, to the model, than a wall with something on it. Hence the door. The fix is a prompt that says what the space should contain, not just what should leave it. Removing with no instruction for what remains is the single most common source of invention. Writing a custom edit prompt for a property photo covers the structure that closes the gap.

What not to do

  • Publish it because the invention is small. Small inventions are the ones a buyer finds at the showing and uses to doubt the rest.
  • Crop the invention out. A cropped room is a smaller room, and a crop that hides an edit is still an edit.
  • Run the same prompt again hoping for a different result. Change the prompt or use the original.
  • Edit the edit. Each generation on a generated image compounds what it got wrong.

FAQ

Questions on this topic

What should I do if an AI edit added a window or door that is not there?

Reject that version and use the original. If the edit matters, run it again with a prompt that names the wall and says to keep it blank with no window, door or fixture, then compare again. If the second attempt invents something else, publish the original.

Can I crop out the part of the photo the AI invented?

No. A cropped room is a smaller room, and a crop that hides an edit is still an edit. Use the original or a corrected version that passes the count.

What if the photo with the invented detail is already on the MLS?

Replace it the same day everywhere it appears: MLS, property page, social posts. Add a line to the remarks that a photo was replaced. If a buyer has asked, tell them plainly and show the original.
