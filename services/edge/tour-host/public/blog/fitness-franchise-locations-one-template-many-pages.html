Fitness franchise locations: one template, many pages

Give every franchise location its own page from one shot list and script, so each shows its own floor, hours and team while the brand stays consistent.

October 28, 2026 · 4 min read · by Rendprop

Short answer. A fitness franchise should give every location its own page, built from the same shot list, the same voiceover script and the same details fields, so each page shows that location's actual floor, hours and team while the brand reads the same across all of them. The template is a checklist, not a piece of software: a fixed order of photos, a script with blanks, and one page per site.

Run a fitness franchise the way a prospect experiences it: one location at a time. Each site gets its own page with its own photos, its own hours, its own team and its own enquiry form, built from a shared template so the brand reads the same everywhere.

The template is not software. It is a fixed shot list, a voiceover script with blanks for the location's name and hours, and a rule that every page uses the same fields in the same order. A prospect in one suburb sees their gym; head office sees twelve pages that match.

Why one brand page fails the prospect

A prospect searching for a gym near them finds the brand page, sees a stock photo of a different location's floor, and has to find the locations list, the right pin, and then a phone number. Most stop before the pin. A location page skips all of that: the floor they will train on, the hours of that site, the manager's face, and a form that asks which day they want to come in. The brand is in the sign on the wall and the consistent way the page is laid out, not in a stock photo.

The shot list template

Every location shoots the same ten photos in the same order, at the same time of day, from the same positions. Write it down, give it to every manager, and check the first set from each site before it goes up.

  1. Storefront from the car park with the sign readable.
  2. Reception from the door, counter clear.
  3. Training floor, wide, from the entrance.
  4. Training floor from the far end looking back.
  5. Free weight area, straight on.
  6. Cardio line with whatever it faces.
  7. Class studio, empty, set for the signature class.
  8. Changing room, clean and lit.
  9. The feature this location has that others do not: the pool, the turf, the rooftop, the kids' room.
  10. The manager or a coach at the desk, with their permission, for the contact card photo if you use one.

Shoot at the quiet hour, usually early afternoon on a weekday, so the floor reads clearly and no member's face is in frame without consent. Same lens, same height, level. Skip AI edits on franchise photos; a location's page must match what a prospect sees when they walk in, and twelve sites editing differently breaks the consistency the template exists for.

The voiceover script with blanks

Write one thirty-second script and leave blanks for the location name, the opening hours, the signature class times and the manager's name. Each location records it in their own voice or uses an AI voice reading the filled-in script. The result is twelve videos that say the same things in the same order, each true for its own site. Word-by-word captions carry the hours for viewers with the sound off.

Worked example: a twelve-location franchise rolling out in a month

A franchise with twelve sites across two cities sends the shot list and the script to every manager on a Monday. Each manager shoots the ten photos on a Tuesday or Wednesday afternoon, fills in the script, and records the voiceover at the desk. By Friday there are twelve listings, each in the gyms and studios mode with that site's hours and membership options typed in. Each video runs the same route from the car park to the changing room and names its own classes. Head office checks each page for the ten shots in the right order, then each location puts its own link on its own social accounts and the sign in the window. Enquiries from all twelve arrive in one inbox, per listing and all together, and the regional manager sees which sites are getting visits booked and which are not.

Keeping twelve pages consistent

  • Same fields, same order. Hours, membership, feature. If one site adds a paragraph about its parking, every site does.
  • Same voiceover structure. Blanks filled, nothing added.
  • A review step. One person at head office checks each page against the shot list before the link goes out.
  • Teams. Managers build their own pages in a shared workspace; the regional team works in the same one.
  • A refresh date. Every site reshoots when the floor changes, or every year, whichever first.

What goes wrong with franchise pages

  • Stock photos. The prospect walks into a different gym from the one on the page.
  • One site's photos reused for another. Same problem, with the added cost of a member recognising the wrong floor.
  • Hours copied from the brand site. Each location's hours differ. Type them per site.
  • Managers improvising the shot list. Twelve different pages, no brand.
  • Enquiries going to twelve inboxes. Nobody can see whether the rollout is working.

FAQ

Questions on this topic

Should a fitness franchise have one page or one per location?

One per location. A prospect wants their gym: its floor, its hours, its team. The brand consistency comes from using the same shot list, script and fields at every site, not from a single page with stock photos.

What is the template, exactly?

A fixed shot list of ten photos in a set order, a thirty-second voiceover script with blanks for the location's name, hours and classes, and a rule that every page uses the same details fields. It is a checklist, not a piece of software.

Who builds each location's page?

The site manager, from the template, with a review step at head office before the link goes out. Teams exist so the regional manager can work in the same workspace without building the pages; check the current team options in the app for the specifics.

Where do enquiries from twelve locations go?

To one inbox, per listing and all together, so the regional team can see which sites are booking visits and which need help. Each location can still handle its own replies.
