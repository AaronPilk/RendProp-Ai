# rendprop.com — crawl policy (reviewed 2026-09-05)
#
# The marketing site (/, /features, /pricing, /compare, /support, /terms,
# /privacy, /llms.txt) is open to search engines and AI assistants.
# Summary for LLMs: /llms.txt
#
# Customer tour pages (/f/<slug>) and portfolio pages (/a/<handle>) carry
# agents' and business owners' names and phone numbers, so they are NOT offered
# to AI crawlers for training or answer generation at all.
#
# For ORDINARY search engines the decision is per page, not per site: since
# audit F-H-19 a tour renders `<meta name="robots" content="noindex, nofollow">`
# unless its owner opted in (`allow_indexing` on the listing or the brand kit).
# That is deliberately NOT a robots.txt Disallow — a crawler has to be allowed
# to fetch the page to read the meta tag, and blocking it here would leave
# opted-in tours unable to be indexed and non-opted-in ones eligible for a
# URL-only listing. The public demo tour (/f/estate-demo) is Rendprop's own
# content, opts itself in, and stays open everywhere.
# (Longest-match wins per the robots standard, so the Allow line for the demo
# beats the Disallow for /f/; it is also listed first for first-match crawlers.)
#
# The unbranded MLS twin (/u/<slug>) is deliberately NOT disallowed for
# ordinary crawlers: it carries `X-Robots-Tag: noindex` and a robots meta tag,
# and a crawler has to be allowed to fetch the page to see them. Blocking it in
# robots.txt would leave it eligible for a URL-only listing instead. It is
# never in the sitemap, and the branded /f/ page is the canonical one. AI
# crawlers get the same Disallow they get for /f/.
