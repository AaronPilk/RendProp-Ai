# The AI-enhancement pipeline (providers/, router, cost_ledger, enhance, cli) is
# STDLIB-ONLY on purpose — it runs anywhere Python 3.10+ is, no install needed:
#
#     python cli.py estimate --rooms 8 --declutter --restage --hero
#
# Provider calls (Gemini, fal, Anthropic, Supabase REST) go over urllib with
# base64 data URIs, so no SDKs are required. Add these only if you want them:

# boto3>=1.34        # only if you host input frames on R2 instead of inline base64
# httpx>=0.27        # optional: swap providers/base.py off urllib onto httpx

# System binaries (NOT pip): ffmpeg + ffprobe are required for VIDEO mode in
# enhance.py (keyframe extraction / segmentation). Image mode and the cost-test
# CLI need neither.  macOS: `brew install ffmpeg`.
