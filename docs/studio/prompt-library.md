# Prompt library

Open **Prompt library** in Creative Studio. Start with a recipe, describe what is
actually visible in the source, set the source duration, and match the reference
labels to the files you will attach. Review the prompt and the separate model
settings before copying or exporting it. Opening, saving or copying a prompt does
not upload media or start a paid generation.

Photo-generation recipes use a whole-second clip length. Video recipes can use
the measured source length, including fractions of a second. The experimental
multicamera recipe explains the distinct video-edit settings and the provider's
authorized portrait-reference requirements.

The initial ten recipes cover room reveals, feature details, exteriors, original
walkthrough edits, agent cutaways, listing teasers, approved presenter briefs,
experimental multicamera performance, twilight concepts and staged-room concepts.
All generated-result quality starts **untested**. Camera-angle and lighting
experiments can change property facts and need comparison with originals.

Save a recipe variation or paste a prompt you obtained elsewhere. Keep its source
link, describe what changed, and record your own result notes. Saved entries are
personal to your account within the current workspace and sync across browsers.
They are not automatically shared with every agency member. Changing accounts or
workspaces loads that account's collection; revisions prevent one device silently
overwriting another device's work.

The catalog is model-aware preparation. It does not install third-party skills or
add a new Seedance provider route. Presenter generation stays disabled, and the
Presenter execution workflow retains its independently approved fixed server
instruction. A library prompt cannot bypass likeness approval, media ownership,
quotes, budgets or output review.
