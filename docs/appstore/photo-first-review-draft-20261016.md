## Reviewer workflow for the next candidate

Rendprop's primary Realtor workflow is property photos → optional AI photo edits → Make a video → a mobile property website. A recorded drone-style walkthrough is an optional separate tool. It does not replace the selected photo-based listing video.

Sign in with Apple, choose Home → Get started, enter the property address and save. Open Photos or AI Photo Studio to import photos. Start with landscape photos for a listing/website, keep the phone level, and use 0.5× when needed to fit the room. Orientation is identified from actual image dimensions as previews load; an unavailable preview is Unknown. Portrait photos are suited to social video. A wrong-orientation image is not silently stretched or altered.

Original is the default editing source. Saved edits stay separate; Photo versions supports adjacent-photo navigation, comparing, editing the current original and selecting/removing a listing version. Bulk AI Photo Studio remains. Publication and stored source/history are separate actions.

Make a video first asks Listing (16:9 landscape) or Social media (9:16 portrait). Select photos in the desired sequence; later imports append to the existing gallery. Scene motion is automatic and varied; optional narration/style controls are secondary. Review significant framing loss before creating. There is no required voiceover, caption text for every photo or single fly-through motion choice.

After server acceptance, progress/status and recovery refer to the saved job. A lost reply is checked before a duplicate request is considered. Review opens the matching completed video; saving/exporting, choosing it for the website and publishing remain explicit. A chosen landscape property video can lead the website without requiring a recorded walkthrough. Tag rooms requires recorded walkthrough footage and explains that prerequisite.

Website design offers the basic site and two distinct premium previews. The premium upgrade is a one-time consumable for ONE property, currently proposed at $25 USD; actual localized Apple price and verified entitlement control the transaction. The product remains Sandbox-only/production-off until genuine purchase and recovery acceptance. A preview is not a purchase.
