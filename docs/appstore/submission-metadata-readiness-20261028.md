## How the files map to the uploader

`asc.py metadata` reads `description.txt`, never `description_team_seats.txt`. The narrow `catalog_copy.py` selects the Team description and review-note variants only with `--include-team-seats`, after the native allowlist is opened; its apply path also requires an explicit Team activation confirmation. `asc.py review` reads `review_notes.txt` by default and `review_notes_team_seats.txt` only with `--include-team-seats`. Both review-note files fit Apple's 4,000-character limit. The default files describe the four base plans and both consumables with explicit activation conditions. They do not claim a dormant purchase button or premium public website is reachable now. The Team variant also describes its separate activation condition; it is not evidence that Team 4–9 is offered.

The broad review helper now patches only contact fields and tracked notes on an existing App Review Information record. It never reads or writes demo credentials or `demoAccountRequired`, and it refuses to sync notes while that flag is false. The narrow `catalog_copy.py` also refuses its copy plan until the demo-required flag is true. App Store Connect's secure UI is the handoff for the reviewer login. This protects a provisioned account from being reset to “no demo required” by a later helper run.
