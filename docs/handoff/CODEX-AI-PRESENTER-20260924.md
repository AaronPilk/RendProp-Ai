## What was built

- Studio Home entry and branded, lazy-loaded Presenter workflow: reusable
  subject-approved profiles, shared property briefs, exact source/revision approval,
  quotes, separate estimate/maximum consent, durable submission/recovery, progress,
  private output review, rejection and accepted-output import.
- Server measurement and hash verification of source/reference media, fixed
  versioned generation instructions, atomic workspace cost reservations, and one
  provider POST per durable job. Unknown outcomes retain their hold and never
  automatically retry or switch providers.
- Existing native upload/quota/gateway/provenance reused for accepted output.
  Review applies to actual generated bytes. Privacy and disclosure follow tracked
  derived edits, reflection outputs and native renders; revocation prevents newly
  issued access, including replay paths and public portfolio cards. Previously downloaded/issued capabilities
  cannot be recalled instantaneously.
- A service-only recovery/cleanup function, **not scheduled or activated**. A real
  release needs an authenticated scheduler, error monitoring and actual billing
  reconciliation. A completed provider job and its final charge are separate facts.
- Original-only editor handoff remains usable without generation and preserves
  the uploaded performance, original audio and asset identity.
- Prompt library in Creative Studio, available without creating a property:
  ten original recipes, scene/timeline adaptation, copy/export, custom prompts,
  source links and personal test feedback. Saved collections use the existing
  user/workspace document store with revision conflict and uncertain-save recovery.
  This is preparation, not a new Seedance generation adapter. Library text cannot
  bypass Presenter approval or alter the fixed server dispatch instruction.
- Auth bundle reduction using the same official Auth SDK version and existing
  storage key/PKCE settings. Browser tests cover code exchange, reload, cross-tab
  session state and local sign-out with synthetic responses.
