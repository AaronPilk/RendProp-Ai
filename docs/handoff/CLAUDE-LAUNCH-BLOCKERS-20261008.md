## Decisions I made that Aaron should confirm (none lower the margin)

1. **Commission assumption.** `apple_commission_bps = 1500` (Small Business Program). Codex is right that approval ≠ effective period. If the first payout shows 30%, run
   `update public.app_config set value = value || '{"apple_commission_bps":3000}'::jsonb, updated_at = now() where key = 'serving_envelope';` — envelopes drop to Starter 807¢ / Pro 1682¢ / Team 4307¢ immediately (edge reads it per call; no deploy).
2. **Holds use the catalog price, not the documentation bound.** The funded model held 31.1¢ per Gemini image (max tokens); that would have blocked a 16-photo batch on a trial. Ceiling mode holds the catalog price (6.7¢) — the same number the ledger records — so the envelope is spent exactly once. The 25% margin buffer absorbs catalog drift; keep `ai_routes.unit_cents` current.
3. **Free tier = 300¢ lifetime + one listing hosted with no deadline.** Hosting an idle free listing costs roughly a cent a month (R2 storage + Worker delivery); AI is the only real cost and it is capped for life. Knobs: `free_published_listings` (0 turns the free listing off) and `free_lifetime_cents`. A lapsed **subscriber** is different: the whole workspace, including its free-slot listing, follows the 90-day grace in Terms §6 (org-level deadline, as before). Per-listing hosting rules would be a follow-up.
4. **Trial money.** Intro week and Sandbox trials: 500¢ per workspace per month, from a 29,000¢/month pool. The pool alert fires at 80%. The trial plan's meters (3/60/4/2/1) still apply.
5. **Sandbox re-grants.** One grant per receipt; a NEW Sandbox purchase after a window ended can open another (needed so a later App Review can buy again). Money is still bounded by 500¢/month per workspace and the pool. TestFlight testers, owner-created Sandbox testers and App Review all produce Sandbox receipts; every one of them draws from that pool.
6. **Richard Tocado** (free, lapsed Apple, 396¢ lifetime) is over the sample today. Add a testing grant if he is a launch tester, otherwise he sees the paywall copy.
