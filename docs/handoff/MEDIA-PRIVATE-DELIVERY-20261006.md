## Practical limits

Public authorization is current on every new byte/conditional request, without CDN replay. Bytes already downloaded or streaming in flight cannot be recalled. A private URL already issued to an authorized native/Studio reader is a capability for its remaining <=600-second lifetime; there is no claim of instantaneous revocation of that capability or downloaded copies.

Each proxy range request currently assembles the authoritative public tour two or three times rather than using a single narrow SQL RPC. This imposes additional database reads and latency. Root/pricing owner must include those reads and media-request volume in hosting costs; they are not included in an AI-only margin claim.

If a photo provider completed but its bytes were never successfully committed to R2, the current handler has no durable provider-result reference from which to repeat that download. That failure remains a sanitized saved-request error with the incurred liability retained; retry cannot authorize another generation. Committed output recovery is tested; uncommitted provider-output recovery is not claimed.
