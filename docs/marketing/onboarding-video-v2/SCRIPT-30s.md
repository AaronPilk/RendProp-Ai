# Rendprop — onboarding video v2, 30-second cut-down

Four beats from the SAME recording as `SCRIPT.md` (same `tour-raw.mp4`, same
`marks.txt`) — this file only re-narrates them shorter and drops the rest.
Build with `--only-scripted` so the other segment ids in `marks.txt` are
dropped instead of showing up caption-less. See
`docs/marketing/onboarding-video-v2/README.md` for the exact command.

No hooks: at 30 s there is nothing left to loop back for. No title card
(`--title-seconds 0`); ends on the CTA card + the brand card, same as the
full cut.
